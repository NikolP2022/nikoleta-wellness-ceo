# Nikoleta Wellness CEO

PWA για CRM, ραντεβού, πελάτες, συνεργάτες, Tanita, προγράμματα, follow-ups, planner, οικονομικά, έγγραφα, ταξίδια και ειδοποιήσεις.

Τα επιχειρησιακά δεδομένα αποθηκεύονται στο Supabase Cloud ανά λογαριασμό χρήστη και η εφαρμογή συγχρονίζει τις αλλαγές μεταξύ συσκευών μέσω Supabase Realtime.

Η εφαρμογή χρησιμοποιεί publishable key στο frontend και Row Level Security (RLS) στη βάση. Δεν χρησιμοποιείται service-role key στον browser.
