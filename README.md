# Nikoleta Wellness CEO

PWA για CRM, ραντεβού, πελάτες, συνεργάτες, Tanita, προγράμματα, follow-ups, planner, οικονομικά, έγγραφα, ταξίδια και ειδοποιήσεις.

Τα επιχειρησιακά δεδομένα αποθηκεύονται στο Supabase Cloud ανά λογαριασμό χρήστη και η εφαρμογή συγχρονίζει τις αλλαγές μεταξύ συσκευών μέσω Supabase Realtime.

Η εφαρμογή χρησιμοποιεί publishable key στο frontend και Row Level Security (RLS) στη βάση. Δεν χρησιμοποιείται service-role key στον browser.


## Learning Center — δεύτερη ανεξάρτητη εφαρμογή

Η δεύτερη εφαρμογή βρίσκεται στον φάκελο `/learning-center/` και λειτουργεί ως ξεχωριστό PWA με δικό του manifest, service worker και τοπική βάση IndexedDB. Δεν χρησιμοποιεί το Supabase της κύριας εφαρμογής και δεν αποστέλλει δεδομένα σε cloud.

Περιλαμβάνει αρχική οθόνη, φακέλους σεμιναρίων, ηχογράφηση μέσω MediaRecorder με τμηματική προσωρινή αποθήκευση, ανέβασμα αρχείων ήχου, πεδίο απομαγνητοφώνησης, σημειώσεις, περίληψη, εκπαιδευτικό υλικό και εξαγωγή αρχείων για μεταφορά με USB.

Η απομαγνητοφώνηση Whisper και η τοπική παραγωγή εκπαιδευτικού υλικού με μοντέλο AI είναι επόμενη φάση και δεν περιλαμβάνονται ακόμη στην πρώτη έκδοση. Η εφαρμογή απαιτεί HTTPS και άδεια μικροφώνου για την ηχογράφηση.


### Πλήρες αντίγραφο και μεταφορά σε νέα συσκευή

Από τις Ρυθμίσεις της εφαρμογής Learning Center επιλέγεται «Δημιουργία ΠΛΗΡΟΥΣ αντιγράφου (με ήχους)». Το αρχείο JSON περιλαμβάνει τις εγγραφές, τα κείμενα, τις σημειώσεις και τα δεδομένα των ηχογραφήσεων. Στη νέα συσκευή ανοίγεται η ίδια εφαρμογή και επιλέγεται «Επαναφορά δεδομένων». Η επαναφορά αντικαθιστά τα υπάρχοντα δεδομένα και πρέπει να προηγείται αντίγραφο ασφαλείας της νέας συσκευής.

**Σημαντικό:** το αντίγραφο μπορεί να γίνει μεγάλο όταν περιέχει πολλές ώρες ήχου. Απαιτείται επαρκής ελεύθερος χώρος και μνήμη στη συσκευή. Φυλάσσεται σε δύο ανεξάρτητα σημεία (π.χ. υπολογιστής και USB). Η τοπική βάση IndexedDB δεν συγχρονίζεται από μόνη της μεταξύ συσκευών. Η ηχογράφηση απαιτεί HTTPS και άδεια μικροφώνου. Η απομαγνητοφώνηση Whisper/AI δεν έχει υλοποιηθεί ακόμη.
